## 使用原则

- 当前代码、Git 历史、部署记录和运行时验收优先于历史描述。
- 已冻结权限不能由页面显隐或临时任务说明反向改写；变更必须新开 SPEC。
- 文档记录可追溯决定和事实，不能代替后端授权、数据库约束或测试。
